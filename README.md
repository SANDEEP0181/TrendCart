# TrendCart

TrendCart is a simple India-focused e-commerce website prototype for clothes and shoes.

## Features
- Customer storefront
- Product catalog
- Size-wise stock support
- Shopping cart
- COD checkout
- Customer orders
- Admin product management
- SQLite database
- Express backend

## Project structure
- `index.html` - customer storefront
- `cart.html` - shopping cart
- `checkout.html` - checkout
- `admin/` - admin panel
- `backend/` - Express + SQLite API

## Local setup
1. Install Node.js.
2. Open PowerShell in `backend`.
3. Run `npm install`.
4. Run `node server.js`.
5. Serve the root folder on port 8000.
6. Serve `admin` on port 3000.

This is a prototype. Production deployment should use secure server-side authentication, a hosted database, HTTPS, and a real payment gateway.
